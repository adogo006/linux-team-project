# 1. 로그인

## 입력

- 둘 중 하나라도 입력치 않았다면  
  "아이디와 비밀번호를 제대로 입력해라" (빨간 글씨)

```
API << 아이디, 비밀번호
해당 아이디, 비밀번호 DB에서 찾음
일치하지 않는 경우 : 오류 반환 (0으로 반환)
일치하는 경우 : 해당 토큰값을 반환
API >> 토큰값
```

# 2. 회원가입

## 닉네임

- 한글, 영어, 숫자 (2~12자)  
  예외 처리 (실시간 확인)  
  예외 처리해야 중복 확인 버튼 가능 (글씨만 파란색)

```
API << 닉네임
중복확인
API >> 중복 여부(T,F)
```

- 버튼 변환 (파란색 체크 표시 + 테두리)
- 다시 수정할 경우  
  처음부터 다시 예외 처리 (실시간 확인)
  버튼 검은색으로 되돌리기

## 아이디

- 영문, 숫자 (2~12자)
  '''
  닉네임과 동일 (API 입출력 포함)
  '''

## 비밀번호

- 영문, 숫자, 특수문자(8~자)  
  실시간 확인
- 재입력 동일

## 회원가입 완료 버튼

- 닉네임 중복 확인  
  아이디 중복 확인  
  비밀번호 양식 준수  
  재입력 동일
- 전부 해당해야 버튼 명료화.

```
API << 닉네임, 아이디, 비밀번호
해당하는 유저에 대한 고유 토큰(정수형 USER ID > 1)을 할당
새로운 닉네임, 아이디, 비밀번호, 토큰 DB 등록
```

- DB에 정보 추가와 동시에 로그인 세션으로 복귀

## 예외

- 정말 드물지만 다음과 같은 경우가 있을 수 있다 :
  사용자 A와 B가 동시에 같은 아이디로 중복한 경우...  
  고유 토큰이 존재한다고 생각하고... 비밀번호까지 겹쳐야하는...  
  생각 안해도 될 것 같다!
